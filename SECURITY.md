# Security and private material

Do not post exploits containing credentials, owner data or unreviewed game-derived
payloads to a public issue. Use GitHub's private vulnerability reporting when it
is actually enabled, or contact the repository owner through an established
private channel. This seed does not claim that reporting feature is enabled.

Before importing files, validate structure and bounds. Treat disc images,
archives, firmware, save states, external launch requests and metadata as
untrusted inputs. Normal game access does not authorize arbitrary filesystem
paths, executable downloads or access to another app's private data.

Do not request games, proprietary firmware, EEPROM keys, signing material or
private saves in public bug reports. Generated minimal fixtures are preferred.
